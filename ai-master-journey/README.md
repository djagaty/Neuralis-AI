# NEURALIS Phase 2.1 — AI Engineering & Full-Stack Roadmap

## Program Overview & Goals
This repository contains source code, hands-on exercises, and assignment deliverables for the **NEURALIS Phase 2.1** program. The goal of this track is to master modern AI engineering—progressing from Python foundations and React frontends to LLMs, orchestration frameworks, and autonomous agent architectures.
